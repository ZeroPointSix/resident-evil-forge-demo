# Containment Pulse

Original 24-second, 80 BPM electronic encounter cue, composed for this demo.
All notes, FM-like bell tones, bass, kick and noise percussion are generated by
`tools/audio/make_encounter_theme.py`. No recordings, sample packs, Capcom assets,
melodies from existing works, or third-party audio are used. The score and PCM
are deterministic with seed `20261004`. This original asset and its generator
are covered by the repository's MIT license.

Regenerate from the repository root (Python 3 and ffmpeg with libvorbis):

```sh
python tools/audio/make_encounter_theme.py
python tools/qa/validate_music.py --root .
```

Release resource: `assets/re_demo/sounds/music/containment_pulse.ogg`.
Registered event: `re_demo:encounter_theme`, streamed mono Vorbis at 44.1 kHz.
It is opt-in, plays once and does not replace Minecraft's background music.

```text
/playsound re_demo:encounter_theme music @s ~ ~ ~ 0.65
/stopsound @s music re_demo:encounter_theme
```

Enable Music and Master volume. Cheats or operator permission are needed for
these vanilla commands. The controlled-client fixture plays this event through
the installed JAR and records the actual client output through an isolated
PulseAudio monitor. The MP4 is not dubbed with the source Ogg afterward.

Audit note: 20261004.
